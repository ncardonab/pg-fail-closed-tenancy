How the repo was built, step by step

Steps 1 to 4 build the database side: a throwaway Postgres, two roles, tenant tables with row-level security forced on, and an append-only audit log. Steps 5 to 8 add the code that scopes each transaction to one tenant, then prove the protection holds: 19 tests run as app_user, six deliberate breaks were all caught, and CI runs the suite plus a security gate. The two highlighted steps are the protection and the proof; the tag in the top right corner of a step names the diagram that covers it in detail.
